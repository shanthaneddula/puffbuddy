# Puffbuddy

Puffbuddy is a touchscreen product-discovery kiosk for retail environments.

## Product direction
- Browse products by category, brand, series, model, and variant.
- Search and compare products.
- Show real product photography and verified product details.
- Let customers share products or submit product requests.
- Give staff tools to manage the catalog.
- Evolve toward multi-store SaaS with tenant-isolated catalogs.

## Development principles
- Keep kiosk browsing fast and simple.
- Use real, source-verified product images and specifications.
- Never invent missing product details.
- Keep AI-assisted catalog research in staff workflows, with human review before publishing.
- Never commit API keys, credentials, customer data, or production secrets.

## Current source baseline
The integration/app-source branch contains the first Git-managed Next.js/Supabase kiosk baseline. See docs/PROJECT-SETUP.md before running or deploying it.

The existing production kiosk is intentionally kept separate while this source baseline is reviewed and tested.
